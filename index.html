Final-year B.Tech project

Smart Drop

An IoT-based solution for secure and efficient package handling. Co-authored with Juhi Sharma. Supervised by Dr. Prakash Kumar, JIIT Noida.

Smart Drop is a locked delivery box that opens only with a one-time password. A customer books a box and receives an OTP. A delivery partner signs in with a six-digit employee ID, takes the order, and uses the OTP to open the box.

A Raspberry Pi 3 B+ and an Arduino Uno communicate over serial. The Arduino switches a relay that powers a 12 V electromagnetic lock, and a 3.5-inch LCD shows the box state. The Raspberry Pi syncs with a Flutter app backed by Firebase Authentication and Cloud Firestore.

All 12 numbered test cases passed, along with an Arduino to Raspberry Pi communication test. The report is candid about open limits: the system does not yet send notifications, and the EM lock needs continuous power to stay engaged.
